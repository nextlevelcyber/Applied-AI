# Week 4 - LLMs and Prompt Engineering

## Learning Focus

Week 4 introduces language models, large language models, prompting, prompt engineering, zero-shot/few-shot prompting, chain-of-thought style reasoning prompts, and practical LLM application patterns.

## Key Concepts

- Language modeling predicts or generates text based on context.
- LLMs are trained at scale and can perform many downstream tasks through prompting.
- Prompt engineering is the task of designing prompts that reliably guide model behavior.
- Zero-shot prompting gives only an instruction.
- Few-shot prompting includes examples.
- Chain-of-thought style prompting asks for structured reasoning or step-by-step planning.
- LangChain and Streamlit can be used to build context-aware chatbot applications.
- BabyAGI introduces the idea of autonomous task planning agents.
