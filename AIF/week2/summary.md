# Week 2 - Intelligent Agents

## Learning Focus

Week 2 introduces intelligent and rational agents, agent environments, the Turing Test, rational action, and basic Python programming. The lab includes Python installation, Python basics, and agent programming examples.

## Key Concepts

- An agent perceives its environment and acts on it.
- A rational agent chooses actions that maximize expected performance or utility given available information.
- Agent design depends on environment properties, available percepts, possible actions, and performance measures.
- Reflex agents choose actions based on the current percept; they are simple but limited.
- Python is used because it is readable, flexible, widely supported, and has strong AI/ML libraries.
