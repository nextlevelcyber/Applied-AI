# Week 3 - Pillars of AI / Machine Learning Introduction

## Learning Focus

Week 3 introduces machine learning as one of the pillars of AI and continues Python practice. The lab covers program flow control, functions, advanced lists, NumPy, Pandas, and basic data handling.

## Key Concepts

- Machine learning is a way to solve AI tasks by learning patterns from data.
- Python control flow includes conditions, loops, input, and output.
- Functions make code reusable, testable, and easier to maintain.
- NumPy supports arrays, matrices, linear algebra, determinants, eigenvalues, and solving systems.
- Pandas supports tabular data, DataFrames, grouping, filtering, and calculated columns.
