# Week 2 - Program Flow Control

## Focus

Control how a Python program makes decisions and repeats tasks.

## Core Learning

- `if`, `elif`, and `else`
- Comparison and Boolean logic
- `for` loops and `while` loops
- Basic validation of user input

## What To Do

- Practise branching logic with small examples.
- Write loop exercises that process lists or repeated inputs.
- Pay attention to edge cases, because input validation is important for the ICA.
