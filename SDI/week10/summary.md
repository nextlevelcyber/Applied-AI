# Week 10 - Python and Web APIs

## Focus

Retrieve data from a public API and store it locally.

## Core Learning

- Understand API endpoints, query parameters, and responses.
- Use `requests` for HTTP requests.
- Validate response data before storing it.
- Insert or update database records safely.
