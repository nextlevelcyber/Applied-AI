# Week 5 - Data Persistence, Reading/Writing to Files

## Focus

Store and retrieve data using files.

## Core Learning

- Open files in read/write modes.
- Read line by line or read whole files.
- Split text into words or fields.
- Write filtered or transformed content back to a file.

## Local Material

The local `L5.docx` includes examples such as deleting lines containing a term, counting words in a file, and reading names from a file.
