# SDI ICA Starter Project Notes

Created: 2026-06-26

This is the official ICA starter area. Because the module is AI Permission Red, formal implementation should be written manually by the student.

## Local Files

- `ICA/phase_1.py`: official starter with Phase 1 function definitions.
- `ICA/phase_2.py`: currently empty.
- `ICA/phase_3.py`: currently empty.
- `db/CIS4044-N-SDI-OPENMETEO-PARTIAL.db`: provided SQLite database.
- `CIS4044-N ICA Specification-OpenMeteo2025-26 - AMITY.docx`: official specification.

## Suggested Manual Workflow

1. Open this folder in VS Code.
2. Read the specification.
3. Implement one function at a time.
4. Run and record output after each function.
5. Save evidence in the assessment run log.
6. Build the report from your own implementation and testing evidence.
