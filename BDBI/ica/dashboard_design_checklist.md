# Dashboard Design Checklist

## Audience And Story

- [ ] Audience is clearly identified.
- [ ] Dashboard answers specific BI questions.
- [ ] Top-level KPIs appear first.
- [ ] Visuals move from overview to detail.
- [ ] Recommendations are supported by evidence.

## Visual Design

- [ ] Chart type matches the question.
- [ ] Titles are clear and business-oriented.
- [ ] Axes and units are readable.
- [ ] Colours are consistent and meaningful.
- [ ] Slicers/filters are useful and not excessive.
- [ ] At least one new chart type beyond lesson examples is included.

## Analytics

- [ ] Trends are analysed.
- [ ] Forecasting or similar analytics is included where suitable.
- [ ] Outliers or key changes are explained.
- [ ] Visuals are interpreted in the report, not just shown.

## Submission Evidence

- [ ] Screenshots are exported for Appendix 3.
- [ ] Data model screenshot is exported for Appendix 1.
- [ ] Power Query transformation evidence is saved.
- [ ] DAX measure evidence is saved.
- [ ] Final `.pbix` file and PDF report are ready.
