# Week 7 - Dashboard Design and Writing a BI Report

## Focus

Design dashboards for readability and write the BI report.

## Blackboard Status

The Week 7 folder is currently empty.

## Summary

Dashboard design should make the decision path clear: what happened, why it matters, and what should be done next. The report should explain the dataset, business questions, KPIs, visuals, and final recommendations.

## Practice Checklist

- [ ] Define dashboard audience.
- [ ] Arrange visuals from overview to detail.
- [ ] Use clear titles and labels.
- [ ] Avoid unnecessary decoration.
- [ ] Write short explanations for each key visual.
- [ ] Draft final recommendations from the evidence.
