# Week 5 - Data Analytics Using DAX

## Focus

Use DAX to create measures and calculated logic for BI analysis.

## Blackboard Material

- Lecture material
- Lab session

## Summary

DAX lets you define reusable calculations such as totals, averages, year-on-year changes, percentages, rankings, and KPI measures. The ICA rubric includes M and/or DAX evidence, so this week matters directly.

## Lab Checklist

- [ ] Use one measure in a card visual.
- [ ] Use one measure in a chart.
- [ ] Check calculations against source data.
- [ ] Save screenshots/evidence for the report appendix.
