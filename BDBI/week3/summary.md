# Week 3 - Data Modelling and Building Relationships in Power BI

## Focus

Build relationships between tables in Power BI and prepare a usable model.

## Blackboard Material

- Lecture material and video
- Lab session

## Summary

This week is central to the ICA. A strong dashboard depends on a clean data model with sensible relationships, not only attractive visuals.

## Lab Checklist

- [ ] Load multiple related tables.
- [ ] Inspect column types and key fields.
- [ ] Create or verify relationships.
- [ ] Check relationship direction and cardinality.
- [ ] Test whether visuals aggregate correctly.
