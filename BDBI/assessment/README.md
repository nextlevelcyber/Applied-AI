## Current Submission Understanding

The ICA is a Power BI and BI report assessment titled **Business Intelligence Solution and Report**. The brief asks you to design and implement a BI solution from an industry-based dataset using Microsoft Power BI.

The final package should evidence:

- Selected dataset and business context.
- Business questions and KPIs.
- Data preparation and modelling.
- Star or snowflake schema thinking with fact and dimension tables.
- Relationships in the model.
- M and/or DAX manipulation.
- Dashboard visuals and explanation.
- Final recommendations.

## Report Sections Required

The brief/template expects:

- Title page.
- Executive summary with key findings, recommendations, and one or two charts.
- Introduction, including data source and BI requirements/questions.
- Findings based on analysis and evaluation, with screenshots and explanations of Power BI visuals.
- Conclusions and recommendations.
- Appendix: data preprocessing/cleansing evidence.
- Appendix: BI data modelling via star schema, facts, and dimensions.
- Appendix: DAX and M Language evidence.
- Appendix: dashboard screenshots for all dashboard pages.
- Self-assessment table using a 0-100 scale.
